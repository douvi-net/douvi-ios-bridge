# Community conduct

Help people build and learn regardless of experience, language or background. Discuss technical decisions with evidence; criticize code and ideas respectfully.

Harassment, threats, discriminatory abuse, doxxing, credential sharing and promotion of stolen signing identities are not acceptable. Do not publish private conversations, device identifiers or signing information without consent.

Maintainers may edit or remove harmful content, close threads, or restrict participation after reviewing context. Affected contributors can request a private reconsideration through the published maintainer contact once the public repository is launched. Before launch, maintainers must publish that verified contact and enable private security reporting.

These expectations apply to issues, pull requests, discussions and official project spaces.
